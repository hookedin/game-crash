AFTERBURN / HOOKEDIN STUDIO
Flight rules & trust

Place one bet per flight. The first accepted bet starts an eight-second boarding window. All players using the same asset share the rocket. Escape during flight to receive your stake multiplied by the server’s multiplier. Cash-outs count when the server processes them, so network delay matters.

Auto escape is set before boarding and survives disconnection. Its target must be strictly below the crash point; a target at the crash point loses. A flight can crash instantly at 1.00×. At 100× everyone still aboard escapes automatically. Payouts round down to whole wei. Bets the room does not accept, including late bets and duplicate seats, are returned.

This is a developer bet: your stake goes to the game developer’s bank, which pays the result. The server chooses a secret and publishes its hash before boarding, then reveals the secret after the flight. The recorder checks that the secret produces the committed crash point. This checks the commitment; it does not prove an unbiased choice of secret, cash-out timing, or that the developer can pay. The wallet verifies the developer’s signed payment.
